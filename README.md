## 🚀 Featured Projects

### 🧩 HelpHS
**Support, SLA, knowledge base, and AI platform**

The main internal system at Health & Safety Tech, built with FastAPI, React, and PostgreSQL. My work focuses on quality, security, metrics, and applied AI.

**Highlights:**
- Grew the backend test suite from **399 to 1,314 tests**
- Diagnosed an SLA metric that was measuring the wrong event
- Performed security audits across routes and infrastructure
- Identified timing-based user enumeration in the login flow
- Mitigated abusive HTTP header processing from **151 s to 0.01 s**
- Built and evaluated semantic search for the **Helô** assistant
- Calibrated relevance using **40 manually labeled questions**

**Stack:** `Python` `FastAPI` `React` `PostgreSQL` `SQLAlchemy` `pgvector` `ONNX Runtime` `Docker`

### 📈 Income Distribution Analysis — PNAD 2015
**Applied statistics with Python, R, and official IBGE microdata**

- Official IBGE microdata
- Documented a **39,627-record discrepancy** between sources
